# PUBLISH 0.18.0 — device checklist (old posts, compact layout, notepad)

- [ ] Title bar and tab bar are slim; messages appear in one bar at the bottom.
- [ ] Posts: dots — red on ordinary WordPress posts, yellow on WP Studio posts, none on PUBLISH posts. Scrolling past the recent 25 keeps loading older posts; search finds any post. Tap a row to edit; ↗ opens it on the site.
- [ ] Tap a WP Studio post: its tiles keep their look (pictures, crops, text, colours); 9:25 / square tiles sit inside a 9:16 tile on their background colour; rows have 1 or 2 tiles; decorations are a drawing. Text is editable.
- [ ] Tap an ordinary post: a cover tile (featured picture + title), a tile per picture with its caption, then the text. Formatting is plain.
- [ ] Update post: the post shows normally on the site; its dot is gone in Posts.
- [ ] Publish tab: name and a small Publish button on top; categories as small chips at the bottom (scroll sideways, + for new); ? shows help. Publishing without a name or tiles says what is missing. After publishing: "Published · View".
- [ ] Drag a tile in the layout → "Moved · Undo" restores it. Discard while editing → Undo restores the tiles.
- [ ] Tiles: three or more thumbnails per row. Delete a tile → Undo brings it back (with its drawing).
- [ ] Editor: the tile is edge to edge. Style on a picture: the FP star in the Order row (tiny "FP"), a star in Layers.
- [ ] Colour: swatches plus the picker (square, hue, hex, recent colours); dragging previews, one Undo step.
- [ ] Notepad (top bar): type, leave, come back — the note is still there. Copy copies the selection or all; Place puts it on the tile as text; Clear can be undone.
- [ ] Media: scrolling loads all WordPress pictures; search covers them all; tap to download.
