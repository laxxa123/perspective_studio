# PUBLISH Phase 1 (TILES) — device checklist (release 0.16.0)

- [ ] Home → Publish opens TILES with the bottom tabs Tiles · Publish · WP · Settings; the last three say "Coming next"; back arrow and Android back return to Home.
- [ ] `+` makes a 9:16 tile and opens it; the name can be renamed by tapping it.
- [ ] Text: type in the full-screen writer; Done places it; Cancel on a new text removes it; Style changes font (Roboto / Ms Madi), weight, size, colour, alignment, line height, spacing; the box height follows the lines.
- [ ] Media → From phone: one or more photos; the library shows canonical names (`name-yyyymmdd-hash.jpg`); importing the same photo again says "reused"; rename keeps the date and hash; a used picture cannot be deleted.
- [ ] Drag pictures and text: blue guide lines appear at the centre, the margins and other elements' edges; snapping is soft (drag further to break free). Corner resize keeps the aspect; rotation snaps at 45°.
- [ ] Trim: crop with corners / edges, presets (1:1, 4:5, 9:16 …), Reset; Done never distorts the picture.
- [ ] Spiral: the coil of text; Edit the words; Style coils, centre size, turn, spacing.
- [ ] Draw: SKETCH's brushes with stylus pressure over the tile; two fingers pan / zoom; Done adds the drawing; Draw again edits it.
- [ ] Layers: order, select a drawing; Style → Order / Lock / Align to margins.
- [ ] Undo / redo across all of the above.
- [ ] Leave the tile: the gallery thumbnail matches; swipe the app away and reopen: the tile is exactly as left.
- [ ] Duplicate and delete (tap twice) tiles from ⋯.
