# 0.20.0 — Style bar checklist

- [ ] Select a spiral → Style: a slim bar with chips (Font · Weight · Size · Colour · Coils · Centre · Turn · Spacing · Opacity · Align · Order); the tile stays visible.
- [ ] An element near the bottom moves up above the bar when Style opens.
- [ ] Font R / M; Weight 100 / 500 / 900 (hidden for Ms Madi); spiral Size slider 25–100 snaps to 5; Coils 1–5; Centre 50–100 %; Turn 0–360°; Spacing −5–20; Opacity 5–100 %.
- [ ] While dragging a slider the bar fades; letting go is one undo step.
- [ ] Colour: five recent colours and + (picker); a picked colour joins the five.
- [ ] Text: sizes 50 / 100 / 150 / 200 / 300; Align has left / centre / right text alignment then align-to-tile icons.
- [ ] Order row: front, forward, backward, back, lock, FP (not for text).
- [ ] Two fingers on a selected spiral: pinch resizes, twist turns the coil. On text: pinch resizes (settles on an offered size), twist turns the box.
- [ ] Spiral centre knob: drag left / right changes the centre size.
- [ ] Bottom bar (Edit · Style · Duplicate · Delete) is half height with icon and label side by side.
- [ ] Reopen Style: the last chip used is selected.
