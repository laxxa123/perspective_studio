# 0.19.0 — drawing checklist (PUBLISH Draw and SKETCH)

- [ ] PUBLISH tile → Draw: the tile fills the screen; ‹ top-left, ⋯ top-right; one floating bar: colour · brush · eraser · grid · undo · redo.
- [ ] Draw several strokes: the bar and buttons do not hide or flicker.
- [ ] ‹ (or Android back) returns to the tile at once, with the drawing shown. Reopen Draw: the drawing is there.
- [ ] Brush sheet: brush names; size dots; opacity is a strip of tinted cells; five recent colours and +.
- [ ] Eraser: one tap to erase, tap again → the previous brush; the eraser and the brush keep separate sizes.
- [ ] + / colour button: palette, picker, eyedropper — touch the tile, the loupe follows the finger, letting go picks the colour (it joins the five recent colours).
- [ ] Grid toggles the 3 × 3 guides; ⋯ → Show tile underneath on / off; Clear drawing → Undo brings it back; Discard changes → Undo restores them.
- [ ] Close and reopen Draw: brush, size, opacity, colour, grid and show tile are as you left them.
- [ ] SKETCH: no flicker while drawing; eraser on the bar; the brush panel has the opacity strip and five colours; the colour panel has the eyedropper.
