# PUBLISH Phase 2 (WordPress) — device checklist (release 0.17.0)

Needs a WordPress site with the studioview theme 0.9.0 and an Application
Password (Users → Profile → Application Passwords).

- [ ] Tabs read Tiles · Publish · Posts · Settings.
- [ ] Settings: site, user, Application Password → Save and test says "Signed in as … Ready to publish". A wrong password says it was refused. Leave and come back: the fields are still filled. Remove password works.
- [ ] Tiles: + adds a tile at the end of "Next post". Hold a tile and drag: reorder; drag below the line into Drafts (the page scrolls near the edge; a blue bar / highlight shows where it lands). ⋯ Move to Drafts / Move to the post. A quick swipe still scrolls.
- [ ] Editor → Style → Featured picture on a photo (star in Layers).
- [ ] Publish: name, tap categories, + Category for a new one. The tiles show small in rows. Hold and drag a tile to the right third of another row → two halves; to the middle of a half row → it takes the row, the others move above / below; to a row edge → a new row.
- [ ] Publish: a progress card shows the steps; then Posts opens with the post on top. Tiles is empty; Drafts are still there; the photos are still in Media, now named `<post>-<nn>-<id>.jpg` and marked with a globe.
- [ ] On the site: the post looks like the tiles (text lines, trims, spiral, drawing, halves); the cover is the featured picture; categories are set.
- [ ] WordPress Media: each picture once; descriptions read `creative_uid:…`. Publishing another post with the same photo uploads nothing new.
- [ ] Posts → Edit: tiles come back in Tiles, name / categories / layout in Publish ("Editing"); change something, Update post. Removing a drawing deletes the old drawing file on WordPress.
- [ ] Edit a post in wp-admin meanwhile, then Update post from the phone: the warning appears; Publish anyway overwrites.
- [ ] Edit while Tiles has other tiles: "will move to Drafts" → Move and edit.
- [ ] An old WP Studio post (search for it): opens as red-dot tiles — pictures with captions, then the text; Update post makes it a normal post (no red dot), rendered by the new format.
- [ ] Posts → Media: WordPress pictures; tap one to download it into Media, then use it in a tile.
- [ ] Airplane mode: Publish says the site cannot be reached and nothing is cleared.
