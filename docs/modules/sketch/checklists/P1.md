# SKETCH Phase 1 — device checklist (release 0.14.0)

- [ ] Home → Sketch opens straight onto a blank 9:16 page (or the last sketch); Android back: panel → mode → gallery → Home.
- [ ] Draw with a finger and with the stylus: smooth, no visible lag at 60 Hz (and 120 Hz if the phone has it); pressure changes width / darkness; tilting the stylus shades with Pencil.
- [ ] Each preset: Pencil, Pen, Marker, Brush, Soft Brush, Airbrush (keeps spraying while the pen rests), Blender (smudges), Eraser.
- [ ] Brush panel: five sizes and five opacities change the next stroke at once; colour swatches, picker and recent colours.
- [ ] The controls fade while drawing and come back when the pen lifts.
- [ ] Two fingers pan and pinch-zoom smoothly; a fast second finger does not leave a mark; More → Fit / 100 %.
- [ ] Two-finger tap undoes, three-finger tap redoes; the bar's undo / redo too, also after many strokes.
- [ ] After using the stylus, a resting palm / finger does not draw (Settings → Gestures can change this).
- [ ] Layers: add, select, hide, opacity, Multiply / Screen / Overlay / Erase, drag to reorder, rename, duplicate, lock (painting refused with a notice), clear, delete — each undoable.
- [ ] Grid: 3 × 3; 1-, 2-, 3-point; drag vanishing points (horizon follows); opacity, extent, lock, hide.
- [ ] Reference image: import a photo, move / scale / turn it, opacity, lock, hide, remove; it is not in the PNG.
- [ ] Rectangle and lasso selection: paint stays inside; Transform (move, two-finger scale / rotate), Duplicate, Delete, Deselect; undo restores.
- [ ] Swipe the app away mid-sketch and reopen: the sketch, its layers, grid and references are back exactly.
- [ ] Gallery: newest first with thumbnails; New, rename, duplicate, Share PNG, delete (tap twice).
- [ ] More → Save PNG lands in Documents/CREATIVE as 1080 × 1920 without guides or hidden layers; Share PNG opens the share sheet; transparent background setting works.
- [ ] Settings → Brushes: change smoothing / spacing / pressure of a preset, draw, reset the preset.
