# 0.21.0 — Grid, snap and quick actions checklist (SKETCH §32)

- [ ] Tap the grid button: the cube net appears (faces A–F outlined, a faint 4 × 4 square, dots on every face); tap again hides it.
- [ ] The first times: a hint "Hold the grid button for grid options".
- [ ] Hold the grid button (½ s, a tick): the grid options open (None · Cube · 3 × 3 · 1/2/3-point); no Lock for Cube or 3 × 3. Choose 3 × 3, then tap twice: 3 × 3 comes back.
- [ ] Snap on (brush panel chip): start a line near a dot and end near another — both ends land exactly on the dots; a light tick each time. Far from a dot: no change.
- [ ] Snap off: lines start and end where the finger is. On 3 × 3 with Snap on, small dots show the snap points along the lines.
- [ ] Zoomed out to fit, ordinary strokes between dots are not pulled onto dots.
- [ ] Hold the eraser: "Sheet cleared · Undo brings it back"; Undo restores every layer; the eraser is not switched on by the hold. Locked or hidden layers are kept.
- [ ] Tap "Colour" in the brush panel: the five become black, white, light grey, red and the colour in use; the colour in use stays.
- [ ] Choose Marker, size 4, close the app, reopen: Marker is on the brush button with size 4; the app never opens on the eraser.
- [ ] PUBLISH Draw: hold the eraser clears the drawing (Undo in the bar message); tap "Colour" loads the default colours.
