# 0.24.0 — OBJECTS Phase 1a device checklist (OBJECTS §A.13, §84)

### Build
- [ ] OBJECTS opens on Studio · 1 · Build with the seven-block starter; "✓ All blocks visible".
- [ ] Add / Remove / Mark work by tap; the marked block is tinted in the 3D view and the drawing, and turns with ⟳ X / Y / Z.
- [ ] Undo / redo step through builds and question changes; New object starts again.
- [ ] 2D: Fill, Dots, Arrows (tap again turns the arrow), Erase; 6 × 6 / 8 × 8.

### Question
- [ ] Each 3D type (Same object, Turn, View, From views, Count, Cut, Track, Pieces) and 2D type (Turn, Mirror, Same figure, Two steps, Fold & punch) shows the stem figure and five options with one ✓.
- [ ] Changing a setting (axis, turn, side, layer, steps, folds, holes) updates the options at once.
- [ ] ↑ ↓ reorder; ↻ replaces a wrong option; ✎ edits an option; editing a wrong option into the right answer → "Options … are both correct".
- [ ] A hidden block or a floating block is reported with the reason; Commit stays off.
- [ ] Preview: Student without the answer, Author with ✓, rules and explanation; PNG / SVG / JSON share.
- [ ] Commit → "OBJECTS-Q-000001 · v1 saved"; Commit again → v2.

### Question Bank
- [ ] The question is listed; search and the 3D / 2D / type filters work.
- [ ] Tap: sheet, profile, versions (v1, v2 each viewable); Edit opens Studio "Editing … commit saves v3"; Duplicate gives a new id; Variant opens new options for review.
- [ ] Close and reopen the app: questions, versions and the Studio draft are all there.

### Device
- [ ] Nothing sits behind the phone's navigation bar; Android back closes a dialog, then Question → Build → home.
- [ ] Turning the 3D view stays smooth with 30 blocks; options appear without a noticeable wait.
