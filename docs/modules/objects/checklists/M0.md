# 0.23.0 — OBJECTS M0 device checklist (OBJECTS §A.12)

- [ ] Home: the Objects tile opens OBJECTS; ← and Android back return home.
- [ ] The starter object (5 blocks) is framed in the view; the bar sits clear of the phone's navigation bar.
- [ ] One finger turns the view smoothly (no lag); two fingers pan and zoom; pinch never changes the object.
- [ ] Add: tap a block's top / side → a block appears there; tap the floor next to the object → a block; far from it → "Add next to a block".
- [ ] A tap that starts a turn does not add a block.
- [ ] Limits: a 7th block in a row → "At most 6 blocks in each direction"; 31st block → "At most 30 blocks".
- [ ] Remove (eraser): tap a block → it goes; splitting the object shows "⚠ Not in one piece".
- [ ] ⟳ X / Y / Z turn the object a quarter; it stays on the floor; four taps bring it back.
- [ ] Undo / redo step through every change; Clear is undoable; Fit reframes.
- [ ] The three drawings match the object (front-right-top view), lines crisp at every size, no shading.
- [ ] Close and reopen the app: the object is still there.
- [ ] 30 blocks: turning the view stays smooth.
