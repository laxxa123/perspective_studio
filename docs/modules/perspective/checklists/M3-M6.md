# M3–M6 — device checklist (release 0.8.0)

Delivered together at the developer's request. Tick on the Android device.

## M3 — Boxes
- [ ] A new scene opens with one cube on the anchor.
- [ ] Box tool: tap the ground → a 1 u cube appears; tap above the horizon → a hint, nothing placed; the tool returns to Select.
- [ ] Place 6 cubes; move one by dragging its body (it slides on the ground, snaps to 0.1 u, snaps flush to a neighbour).
- [ ] Resize with the coloured face handles (W orange, D blue, H purple); with Cube lock on all sides scale together.
- [ ] Lift with the purple handle on the front vertical edge.
- [ ] Duplicate (+1 u toward VP-R), delete, long press → Duplicate / Stack on top / Bring forward / Delete.
- [ ] Move VP-L, VP-R, VP-V and the horizon in the Perspective tool: every cube stays exact.
- [ ] Display: Construction shows dashed hidden edges and rays for the selected cube; Clean shows edges only.
- [ ] Scene settings (⋯ menu): eye height changes the scale of everything.

## M4 — Document
- [ ] Gallery lists scenes with thumbnails; New 3-point / 2-point.
- [ ] Edit, then kill the app from the recents screen; reopen: nothing lost.
- [ ] Undo / redo every action above (buttons, two-finger tap = undo, three-finger tap = redo).
- [ ] Export PNG 1× / 2× / 4× and SVG (⋯ menu): they match the screen's display mode; the share sheet opens.
- [ ] Export JSON, then Import it in the gallery: an identical copy appears.
- [ ] Backup all (archive icon) → a file in Documents/PerspectiveStudio.

## M5 — Stacking, rects, layers
- [ ] Stack 3 cubes (Box tool on a top face, or drag a cube onto another) and a tall box.
- [ ] Rect tool: Ground, Wall L and Wall R rectangles; move and resize them.
- [ ] Layers panel: add, rename (double-tap), reorder, hide, lock, opacity; tap an item to select it.
- [ ] Everything stays exact when the VPs move.

## M6 — Sketch
- [ ] Sketch: pencil / pen / marker, colours, width; strokes taper naturally with a finger.
- [ ] Eraser removes whole strokes it touches.
- [ ] Snap Soft: a nearly straight line toward a VP straightens; Locked: lines follow L / R / V (or the nearest, Auto).
- [ ] Display → Guides: horizon, VPs and guide lines without objects, as a sketching backdrop.
- [ ] Dragging the perspective in a scene with strokes shows the "strokes stay put" note once.
- [ ] Draw many strokes (hundreds): drawing stays smooth. (NFR-P-02 target: 5,000.)
- [ ] With a stylus (if available): pressure varies the width, and fingers pan instead of drawing.

## App
- [ ] New launcher icon; Settings: theme light / dark / system, grid snap, after-placing behaviour, toolbar position.
- [ ] Android back button: closes panels, then leaves the editor for the gallery.
