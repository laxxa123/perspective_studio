# CUBE Phase 1 — device checklist (release 0.15.0)

- [ ] Home → Cube opens CUBE (Studio · Question Bank · Test · Analysis); back arrow and Android back return to Home.
- [ ] Classic cross net shows "✓ Valid cube net"; Net tool: drag F onto the right of E → "⚠ Net cannot form a cube" with a reason and red faces; Undo restores it.
- [ ] Presets Offset cross, Zig-zag, Long strip all valid; faces keep their artwork.
- [ ] Draw on faces: pen, line, arrow, rectangle, ellipse, polygon; text; stamps (shapes and letters); eraser removes an element.
- [ ] Image tool: pick a photo from the gallery → placed on the tapped face; move, scale, rotate it; crop sliders; opacity.
- [ ] Draw a line across the fold between two faces → it stays one pattern; on the 3D cube it continues round the edge.
- [ ] 3D cube: drag turns it smoothly, pinch zooms, Reset / Front / Top / Right; tap a face in 3D → the same face is selected on the net, and vice versa.
- [ ] Turn a face on the net (properties ↻) → its artwork turns on the 3D cube.
- [ ] Question → Net → Cube → Create question: five cube options, one ✓, four labelled distractors; "✓ Ready to commit".
- [ ] Mark a wrong option correct → validation complains; regenerate an option; edit an option (turn a face) → validation updates.
- [ ] Commit → "CUBE-Q-000001 v1"; Cube → Net with 2 views → commit → CUBE-Q-000002.
- [ ] Question Bank: search, filter by type / distractor; preview; Edit → change → Commit as v2; Versions shows v1 and v2; Duplicate → new id; Variant opens in the Studio.
- [ ] Export PNG and JSON from the bank (share sheet).
- [ ] Close the app (swipe away) and reopen: the Studio draft is back ("Saved"); the bank still lists the questions with their versions.
- [ ] Test and Analysis show "Phase 2" / "Phase 3" only.

## 0.15.0 (design rework)

- [ ] The net sits on a 4 × 4 hairline board; Fit fits the board; New gives a blank cube and Undo brings the old one back.
- [ ] Select a stamp / shape and drag it around: no face ever moves; faces move only with Net (and stay on the board).
- [ ] Snap dots show on every face with Select / Shape / Text / Stamp; a rectangle drawn between dots has repeatable sizes; stamps S / M / L.
- [ ] Pen stroke started on the bare board and crossing faces: only the parts on faces remain.
- [ ] Fill: tap faces with each of the four colours; white clears.
- [ ] Image: the picture covers the board; move / scale / turn it; Done trims it to the faces (continuous across folds on the 3D cube); Cancel drops it.
- [ ] 3D opens as a pop-up (turn, zoom, views, tap a face); the Question step has no 3D panel and its cards use the full width.
- [ ] Question Bank: tapping a question opens its details under it; with more than 10 questions, previous / next pages.
