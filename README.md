# PERSPECTIVE_STUDIO

A 2D perspective drawing skill app: set a horizon and three vanishing points,
construct perspective cubes, and sketch freely or with perspective assistance.

React · TypeScript · Konva · Vite · Capacitor (Android) · Obtainium.

```sh
npm install
npm run dev        # http://localhost:5173
npm test
npm run build
```

Requirements: `PERSPECTIVE_STUDIO_Requirements_Base_*.md`.
Every push to `main` publishes a signed APK as a GitHub Release.
